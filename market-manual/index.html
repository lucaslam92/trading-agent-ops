每日操作手册（细化版）

一、盘前准备（共30分钟）

1打开全球行情（5分钟）

工具：同花顺自选页添加以下品种

  • 纳斯达克 NDX → 看收盘涨跌幅
  • 恒生科技 HSTECH → 看收盘涨跌幅
  • A50期指 CN00Y → 看当前涨跌幅
  • 美10年期国债收益率 US10Y → 看数值
  • 黄金 GC00Y → 看涨跌幅
  • 原油 CL00Y → 看涨跌幅
  • 美股AI龙头：NVDA MSFT META → 看盘后涨跌幅

一句话结论：科技偏强 / 避险偏强 / 中性

2判断今日风险偏好基准（5分钟）

集合竞价（9:15-9:25）对比：

  • 进攻代表：人工智能ETF 515070 或 半导体ETF 512480
  • 防守代表：银行ETF 512800 或 电力ETF 159611
情况结论
进攻ETF涨幅 > 防守ETF今日偏好科技成长
防守ETF涨幅 > 进攻ETF今日偏避险
差异 ±0.2% 以内震荡市，无明显偏好

3筛选今日关键词新闻（10分钟）

工具：同花顺 → 资讯 → 要闻 → 精选/头条，或财联社APP → 电报

必须过滤：含"暴涨""惊天""突发""重磅"的；个股分析；个人大V。

只捕捉关键词：政策/国务院/发改委/工信部 · AI/大模型/OpenAI · 芯片/算力/光模块 · 降息/加息/央行 · 业绩超预期（仅AI半导体龙头）· 机器人/数据要素/低空经济

输出：≤3条新闻，写一句话结论。

4建立今日观察表（10分钟）

→ 见"工具箱"中的今日观察对照表

二、盘中观察（9:30 – 15:00）

5开盘5分钟快速扫描（9:30-9:35）

  1. 同花顺 → 板块 → 行业板块 → 按涨幅排序，看前三名
  2. 昨日龙头：高开>2%且5分钟内无跳水 → 强势；低开<-2%且无法翻红 → 弱势
  3. 涨跌家数：上涨>3000为偏暖；涨停>50且跌停<5为良好

6三个关键时间点

时间观察内容
10:30最强板块是否持续？大盘分时是否在白线上方？
13:15上午强势板块是否冲高回落？有无新板块突然拉直线？
14:30今天放量还是缩量？龙头是否抗跌？

7随时记录资金流向

同花顺 → 板块 → 资金流向 → 今日 → 看净流入（亿）

不需精确数字，只需知道：今日流入主线、流出板块各是什么。

三、盘后复盘（15:00后，约20分钟）

8填写市场结构日记 → 见"每日日记"页

9检验"假强"板块

→ 见"工具箱" — 假强板块快速判断

三条规则：高开低走；无板块跟随；资金净流出。命中2条以上 → 假强。

10判断龙头健康度

→ 见"工具箱" — 龙头健康度评估

指标健康警告危险
收盘价创20日新高仍在5日线上跌破10日线
成交量温和放大20-50%缩量上涨爆量>100%且收阴
分时大盘跌它横盘跟随大盘大盘稳它独跌
板块带动≥3只涨停或>7%板块只有它涨板块跌多涨少

四、第一阶段训练要点（前2周）

  • 不交易，或只买1手（100股）用来感受
  • 每天必须填完日记，哪怕只写一行
  • 周末回顾本周5天日记，找规律
  • 重点训练：开盘5分钟判断"今天可能强/弱"——允许错，但要记录为什么错

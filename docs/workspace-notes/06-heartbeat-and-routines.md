# Heartbeat and Routines

整理来源：`HEARTBEAT.md` 与 `AGENTS.md` 中 heartbeat 相关段落

## 心跳文件作用

`HEARTBEAT.md` 用来定义周期性检查任务。当前文件基本为空，只保留了“留空则跳过 heartbeat API 调用”的说明。

## 当前状态

- 没有配置具体巡检任务
- 默认意味着心跳轮询时通常不会触发额外操作

## 设计意图

heartbeat 适合做：

- 邮件检查
- 日历提醒
- 天气关注
- 最近项目状态巡检
- 定期记忆整理

## 触发后的处理原则

- 有事就汇报
- 没事就返回 `HEARTBEAT_OK`
- 不要把旧任务无限重复带入新心跳

## 当前结论

现有 heartbeat 机制处于“未配置任务”的轻量状态，适合后续按需逐项加进去，而不是一开始就堆很多自动动作。

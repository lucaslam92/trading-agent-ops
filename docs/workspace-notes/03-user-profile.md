# User Profile

整理来源：`USER.md`

## 文档用途

`USER.md` 用来记录用户的基础信息和长期偏好，帮助后续协作更顺手，但应避免把它写成过度收集的“档案”。

## 当前字段

- Name
- What to call them
- Pronouns
- Timezone
- Notes
- Context

## 当前状态

当前模板仍基本为空，说明还没有完成用户画像初始化。

## 后续建议补充

- 用户希望被怎么称呼
- 时区与常用作息
- 在意的项目或长期任务
- 沟通偏好（简洁/详细、中文/英文、要不要主动提醒）
- 明显不喜欢的做法

## 使用原则

- 只记录真正有助于协作的信息
- 不把私人内容扩展成冗余档案
- 有新偏好时及时更新

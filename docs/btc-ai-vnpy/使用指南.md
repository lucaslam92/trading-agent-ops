## 1. 系统概览

本系统是一套基于 [vn.py](https://github.com/vnpy/vnpy) 的 BTC 自动交易框架，核心设计分三层：

```
Binance 行情
     ↓
AI 市场状态识别（规则模型）
  → 判断：趋势上升 / 趋势下降 / 震荡 / 高波动
  → 输出：选哪个策略 + 用什么参数
     ↓
vn.py CTA 策略执行
  → 趋势策略：均线金叉死叉 + ATR 止损
  → 震荡策略：RSI + 布林带 + 中轨止盈
     ↓
风控层
  → 单日亏损上限、连续亏损次数、仓位比例
     ↓
日志 / 回测报告 / 实盘下单
```

**AI 与策略之间的交互方式：**

AI 模块不直接调用下单接口，而是把决策写入 `configs/strategy_runtime.json`。策略在每根 K 线（`on_bar`）读取该文件，版本号变化时才刷新参数。这样策略代码保持稳定，参数动态可控，回测与实盘代码完全一致。

## 3. 安装依赖

### 3.1 创建虚拟环境（推荐）

```bash
python -m venv .venv

# Linux / macOS
source .venv/bin/activate

# Windows
.venv\Scripts\activate
```

### 3.2 安装包

**回测模式**（最小依赖）：

```bash
pip install vnpy vnpy_ctastrategy vnpy_sqlite
```

**模拟盘 / 实盘**（额外需要交易所 Gateway）：

```bash
pip install vnpy vnpy_ctastrategy vnpy_sqlite vnpy_binance
```

**一次性全装**（使用项目 requirements.txt）：

```bash
pip install -r requirements.txt
```

### 3.3 依赖说明

| 包 | 用途 | 何时需要 |
|----|------|----------|
| `vnpy` | vn.py 核心框架 | 必须 |
| `vnpy_ctastrategy` | CTA 策略引擎 + 回测引擎 | 必须 |
| `vnpy_sqlite` | SQLite 数据库驱动，存储 K 线数据 | 必须 |
| `vnpy_binance` | Binance 交易所接入 | 仅模拟盘/实盘 |
| `vnpy_mongodb` | MongoDB 驱动，大数据量时替换 SQLite | 可选 |

## 4. 项目结构

```
trading-agent-ops/
│
├── ai/                         # AI 决策层（不直接下单）
│   ├── regime_detector.py      # 市场状态识别（规则模型）
│   ├── strategy_router.py      # regime -> 策略类型映射
│   ├── parameter_provider.py   # 按 regime 输出参数配置
│   └── config_output.py        # 将决策写入 JSON 文件
│
├── strategies/                 # CTA 策略执行层
│   ├── adaptive_cta_template.py    # 基类：配置热更新、风控、下单辅助
│   ├── btc_trend_strategy.py       # 趋势策略：均线 + ATR 止损
│   └── btc_mean_reversion_strategy.py  # 震荡策略：RSI + 布林带
│
├── configs/                    # 配置文件
│   ├── strategy_runtime.json   # AI 运行时输出（策略读取此文件）
│   ├── backtest_config.json    # 回测参数
│   ├── paper_config.json       # 模拟盘参数
│   └── live_config.json        # 实盘参数
│
├── runner/                     # 运行入口
│   ├── run_backtest.py         # 启动回测
│   ├── run_paper.py            # 启动模拟盘
│   └── run_live.py             # 启动实盘
│
├── services/                   # 基础服务
│   ├── config_service.py       # JSON 配置读写
│   ├── risk_service.py         # 全局风控状态管理
│   └── market_data_service.py  # K 线加载 + 指标计算
│
├── scripts/
│   └── download_data.py        # 从 Binance 下载历史 K 线
│
├── logs/                       # 回测结果 CSV 输出目录
└── requirements.txt
```

## 5. 快速开始：跑通回测

### 第一步：下载历史数据

从 Binance 公开接口下载 BTC/USDT 1h 数据，**无需 API Key**：

```bash
# 下载 2023 年全年（约 8760 根 K 线，耗时约 30 秒）
python scripts/download_data.py --start 2023-01-01 --end 2024-01-01
```

下载完后验证数据是否入库：

```bash
python scripts/download_data.py --check
```

预期输出：

```
数据库中共有 8760 根 BTCUSDT HOUR K 线  [2023-01-01 -> 2023-12-31]
```

**下载脚本完整参数：**

```bash
python scripts/download_data.py \
  --symbol   BTCUSDT     \  # 交易对（默认 BTCUSDT）
  --interval 1h          \  # K 线周期：1m/5m/15m/1h/4h/1d
  --start    2022-01-01  \  # 起始日期
  --end      2024-01-01  \  # 结束日期
  --market   spot           # spot（现货）或 futures（合约）
```

### 第二步：配置回测参数

编辑 `configs/backtest_config.json`：

```json
{
  "symbol":   "BTCUSDT",
  "exchange": "BINANCE",
  "interval": "1h",
  "start":    "2023-01-01",
  "end":      "2024-01-01",
  "rate":     0.0005,       // 手续费率 0.05%
  "slippage": 10.0,         // 滑点（USDT）
  "capital":  1000000,      // 初始资金（USDT）

  "strategy": "BtcTrendStrategy",   // 或 "BtcMeanReversionStrategy"
  "strategy_setting": {
    "fast_window":    10,
    "slow_window":    30,
    "atr_window":     14,
    "atr_multiplier": 1.5,
    "stop_loss_pct":  0.015
  }
}
```

### 第三步：运行回测

```bash
python runner/run_backtest.py
```

终端会输出：

```
=== BTC 回测启动 ===
时间区间: 2023-01-01 -> 2024-01-01
AI 初始配置已写入: regime=range strategy=mean_reversion
加载历史数据 ...
开始回测 ...
=== 回测结果 ===
  total_return: 0.234
  annual_return: 0.234
  max_drawdown: -0.087
  sharpe_ratio: 1.42
  ...
每日净值已保存: logs/backtest_BtcTrendStrategy_2023-01-01_2024-01-01.csv
```

### 切换策略

**跑趋势策略：**

```bash
# configs/backtest_config.json 中设置
"strategy": "BtcTrendStrategy"
```

**跑震荡策略：**

```bash
"strategy": "BtcMeanReversionStrategy"
# 同时替换 strategy_setting 为震荡策略参数：
"strategy_setting": {
  "rsi_window":           14,
  "rsi_long_threshold":   30.0,
  "rsi_short_threshold":  70.0,
  "boll_window":          20,
  "boll_dev":             2.0,
  "stop_loss_pct":        0.015
}
```

## 6. 运行模拟盘

模拟盘使用真实行情，但不实际下单。AI 模块每隔 4 根 K 线自动运行一次，动态更新策略参数。

### 前提

需要额外安装 Binance Gateway：

```bash
pip install vnpy_binance
```

### 启动

```bash
python runner/run_paper.py
```

或指定配置文件：

```bash
python runner/run_paper.py --config configs/paper_config.json
```

### 模拟盘配置说明（`configs/paper_config.json`）

```json
{
  "strategy": "BtcTrendStrategy",
  "ai": {
    "enabled": true,
    "update_interval_bars": 4,   // 每隔几根 K 线运行一次 AI 判断
    "lookback_bars": 100         // AI 使用最近多少根 K 线做判断
  }
}
```

### AI 更新日志

模拟盘运行时，终端会定期出现 AI 更新日志：

```
AI 更新: v3 regime=trend_up strategy=trend_following
参数已更新: version=3 strategy=trend_following regime=trend_up
```

## 7. 运行实盘

> **警告：实盘模式会真实下单，请务必在充分回测和模拟盘验证后再使用。**

### 第一步：配置 API Key

打开 `runner/run_live.py`，找到以下注释段并填入你的 API Key：

```python
# 取消注释并填入真实 Key
from vnpy_binance import BinanceSpotGateway
main_engine.add_gateway(BinanceSpotGateway)
main_engine.connect(
    setting={"key": "YOUR_API_KEY", "secret": "YOUR_API_SECRET"},
    gateway_name="BINANCE",
)
```

### 第二步：调整实盘风控参数（`configs/live_config.json`）

```json
{
  "risk": {
    "max_position_pct": 0.10,   // 单次最多用 10% 资金
    "daily_loss_limit": 0.03    // 单日亏损超 3% 停止开仓
  }
}
```

### 第三步：启动

```bash
python runner/run_live.py
```

系统会弹出安全确认提示：

```
========================================================
  警告：即将启动【实盘模式】，真实资金将参与交易！
  策略: BtcTrendStrategy
  品种: BTCUSDT.BINANCE
========================================================
  请输入 'YES' 确认启动:
```

输入 `YES` 后正式启动。

## 8. 配置文件说明

### `configs/strategy_runtime.json`（AI 运行时输出）

由 AI 模块自动维护，**不要手动编辑**。策略通过读取此文件的 `version` 字段感知参数变化。

```json
{
  "regime":   "trend_up",         // 当前市场状态
  "strategy": "trend_following",  // 当前使用的策略类型
  "version":  5,                  // 版本号，变化时策略刷新参数
  "params": {
    "fast_window": 10,
    "slow_window": 30,
    "atr_window":  14,
    "atr_multiplier": 1.5
  },
  "risk": {
    "max_position_pct": 0.20,
    "stop_loss_pct":    0.015,
    "take_profit_pct":  0.030
  }
}
```

### 各策略参数对照

**趋势策略（`BtcTrendStrategy`）**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `fast_window` | 10 | 快均线周期 |
| `slow_window` | 30 | 慢均线周期 |
| `atr_window` | 14 | ATR 计算周期 |
| `atr_multiplier` | 1.5 | 止损 ATR 倍数（越大止损越宽） |
| `stop_loss_pct` | 0.015 | 固定止损比例（兜底） |

**震荡策略（`BtcMeanReversionStrategy`）**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `rsi_window` | 14 | RSI 计算周期 |
| `rsi_long_threshold` | 30.0 | RSI 低于此值做多（超卖） |
| `rsi_short_threshold` | 70.0 | RSI 高于此值做空（超买） |
| `boll_window` | 20 | 布林带周期 |
| `boll_dev` | 2.0 | 布林带标准差倍数 |
| `stop_loss_pct` | 0.015 | 固定止损比例 |

**风控参数（所有策略通用）**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_position_pct` | 0.20 | 单次最多用多少比例资金开仓 |
| `stop_loss_pct` | 0.015 | 单笔最大亏损（1.5%） |
| `take_profit_pct` | 0.030 | 止盈比例（3%） |
| `daily_loss_limit` | 0.05 | 单日最大亏损（5% 资本，触发后停止开仓） |

## 9. AI 模块说明

### 市场状态判断逻辑（`ai/regime_detector.py`）

按优先级依次判断：

```
1. ATR 当前值 > 近期均值 × 2.0  →  high_volatility（高波动）
2. 布林带宽度 < 0.03            →  range（震荡横盘）
3. 快均线 > 慢均线 + 均线向上 + RSI > 60  →  trend_up
4. 快均线 < 慢均线 + 均线向下 + RSI < 40  →  trend_down
5. 以上均不满足                 →  range（默认）
```

### 状态到策略的映射（`ai/strategy_router.py`）

| 市场状态 | 策略 | 风控调整 |
|----------|------|----------|
| `trend_up` | 趋势策略 | 正常仓位 |
| `trend_down` | 趋势策略 | 正常仓位 |
| `range` | 震荡策略 | 正常仓位 |
| `high_volatility` | 趋势策略 | 仓位减半（10%） |

### 调整 AI 判断阈值

修改 `ai/regime_detector.py` 顶部的常量：

```python
ATR_HIGH_VOLATILITY_MULT = 2.0   # ATR 多少倍算高波动（调大 = 更难触发）
BOLL_RANGE_THRESHOLD     = 0.03  # 布林带宽度阈值（调大 = 更多情况判定为震荡）
RSI_UPPER = 60.0                 # 趋势确认 RSI 上限（调高 = 更难判定为上升趋势）
RSI_LOWER = 40.0                 # 趋势确认 RSI 下限
```

## 10. 常见问题

### 安装问题

**Q: `pip install vnpy` 报编译错误**

vnpy 部分依赖需要 C 编译器。建议：

```bash
# Ubuntu/Debian
sudo apt-get install build-essential python3-dev

# macOS
xcode-select --install
```

**Q: `No module named 'vnpy_sqlite'`**

```bash
pip install vnpy_sqlite
```

---

### 数据下载问题

**Q: 下载时报 `ConnectionError` 或超时**

Binance API 在国内需要代理：

```bash
# 设置代理后再下载
export https_proxy=http://127.0.0.1:7890
python scripts/download_data.py ...
```

**Q: 想下载更长时间的数据**

```bash
# 下载 3 年数据
python scripts/download_data.py --start 2021-01-01 --end 2024-01-01
```

**Q: 想用合约数据而不是现货**

```bash
python scripts/download_data.py --market futures
```

---

### 回测问题

**Q: 回测报 `No data found`**

数据库里没有对应时间段的数据，先运行下载脚本。

**Q: 回测结果 CSV 在哪**

在 `logs/` 目录下，文件名格式：

```
logs/backtest_BtcTrendStrategy_2023-01-01_2024-01-01.csv
```

**Q: `show_chart()` 报错**

服务器无图形界面时正常，结果已保存到 CSV，可忽略此错误。

**Q: 回测结果不理想怎么调**

按以下顺序调整：
1. 先换时间段，确认策略在不同市场环境下的表现
2. 调整 `fast_window` / `slow_window`（趋势策略）
3. 调整 `rsi_long_threshold` / `rsi_short_threshold`（震荡策略）
4. 调整 `atr_multiplier` 控制止损宽度
5. 调整 `max_position_pct` 控制仓位大小

---

### 模拟盘 / 实盘问题

**Q: 模拟盘 AI 多久更新一次参数**

由 `paper_config.json` 中的 `update_interval_bars` 控制，默认 4 根 K 线。1h K 线的话就是每 4 小时更新一次。

**Q: 实盘想禁用 AI，固定参数运行**

在 `live_config.json` 中设置：

```json
"ai": {
  "enabled": false
}
```

策略会一直使用 `strategy_runtime.json` 中当前的参数。

**Q: 如何手动强制切换策略**

直接修改 `configs/strategy_runtime.json`，把 `version` 加 1，策略会在下一根 K 线时自动读取新参数：

```json
{
  "regime": "range",
  "strategy": "mean_reversion",
  "version": 99,
  "params": { ... }
}
```

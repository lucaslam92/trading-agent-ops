# BTC CTA 策略阶段总结

## 当前主推策略

**BtcDonchianBreakoutStrategy**

当前候选参数：

- breakout_window = 50
- exit_window = 20
- atr_window = 14
- atr_multiplier = 1.5
- adx_window = 10
- adx_threshold = 25
- breakout_atr_buffer = 0.1
- stop_loss_pct = 0.015
- next_bar_entry = true
- base_slippage = 5.0
- atr_slippage_multiplier = 0.05

## 为什么选它

这套参数是在以下流程后收敛出来的：

1. 修复回测参数注入 bug
2. 比较均线趋势 / 均值回归 / Donchian 基础版
3. 对 Donchian 做参数优化
4. 加入现实摩擦：下一根 K 线开仓 + 动态滑点
5. 加入 ADX 趋势过滤
6. 对 ADX 参数做 2023/2024 跨年份比较
7. 对 breakout ATR buffer 做 0.0 / 0.1 / 0.2 比较

## 关键对比结论

### Donchian + ADX(10,25) + buffer=0.1

#### 2023
- total_return: 0.07%
- max_ddpercent: -0.04%
- sharpe_ratio: 0.78
- trade_count: 71

#### 2024
- total_return: 0.19%
- max_ddpercent: -0.13%
- sharpe_ratio: 0.74
- trade_count: 170

## 当前判断

- 相比原版 Donchian，buffer=0.1 在 2023/2024 两边都更均衡
- 相比均线趋势策略，这条线更有继续优化价值
- 交易次数仍然偏多，后续仍需继续压缩噪音交易

1. 引入 funding / 更真实撮合
2. 对 2022 再补一轮该参数验证
3. 尝试 cooldown / regime filter

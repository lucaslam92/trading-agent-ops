# 市场监控终端部署说明

本文档说明如何将 `market-terminal` 前端和 `market-api` 后端部署到 Linux 服务器。

## 1. 部署架构

推荐部署形态：

```text
Browser
  |
  | https://your-domain.com/
  v
Nginx
  |-- /                 -> market-terminal/dist 静态文件
  |-- /api/*            -> 127.0.0.1:8000 FastAPI
                         |
                         v
                    market-api
                         |
                         v
                    SQLite market.db
```

前端通过相对路径访问后端：

```text
/api/stream
/api/checklist
/api/journal
/health
```

其中 `/api/stream` 是 SSE 长连接，需要 Nginx 关闭代理缓冲。

## 2. 服务器要求

### 2.1 基础系统

推荐：

- Ubuntu 22.04 LTS 或 Ubuntu 24.04 LTS
- Debian 12
- 2 核 CPU
- 2 GB 内存以上
- 20 GB 磁盘以上

最低可运行：

- 1 核 CPU
- 1 GB 内存
- 10 GB 磁盘

如果使用 `eastmoney` 实时行情源，服务器需要能访问东方财富和 Yahoo Finance 相关接口。

### 2.2 系统依赖

需要安装：

```bash
sudo apt update
sudo apt install -y \
  python3 \
  python3-venv \
  python3-pip \
  nodejs \
  npm \
  nginx \
  rsync \
  curl
```

建议版本：

- Python：3.10+
- Node.js：20.x LTS
- npm：10+
- Nginx：1.18+

如果系统源里的 Node.js 版本过低，建议使用 NodeSource 或 nvm 安装 Node.js 20。

### 2.3 网络和端口

需要开放：

- `80/tcp`：HTTP
- `443/tcp`：HTTPS，推荐生产环境启用

后端 FastAPI 默认监听：

```text
127.0.0.1:8000
```

该端口只需要本机访问，不建议直接对公网开放。

## 3. 目录规划

推荐部署目录：

```text
/opt/trading-agent-ops/
  market-api/
    .venv/
    .env
    market.db
    main.py
    ...
  market-terminal/
    dist/
      index.html
      assets/
```

其中：

- `market-api/.env`：后端运行配置。
- `market-api/market.db`：SQLite 数据库。
- `market-terminal/dist/`：前端构建产物。

## 4. 后端部署

### 4.1 上传代码

可以通过 git clone、scp 或 rsync 将仓库放到服务器，例如：

```bash
git clone <repo-url> /opt/source/trading-agent-ops
cd /opt/source/trading-agent-ops
```

### 4.2 创建 Python 虚拟环境

```bash
cd /opt/trading-agent-ops/market-api
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### 4.3 配置环境变量

复制示例配置：

```bash
cp .env.example .env
```

常用配置：

```env
ADAPTER=mock
TICK_INTERVAL=2.2
TUSHARE_TOKEN=
DB_PATH=market.db
```

行情源说明：

- `mock`：模拟数据，默认可用。
- `eastmoney`：实时 A 股行情，需要服务器能访问外部行情接口。
- `tushare`：Tushare 数据，需要 `TUSHARE_TOKEN`。

生产环境建议：

```env
ADAPTER=eastmoney
TICK_INTERVAL=5.0
DB_PATH=market.db
```

### 4.4 手动启动后端

```bash
cd /opt/trading-agent-ops/market-api
.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
```

健康检查：

```bash
curl http://127.0.0.1:8000/health
```

期望返回：

```json
{"status":"ok"}
```

### 4.5 systemd 服务

推荐使用 systemd 管理后端：

```ini
[Unit]
Description=Market Terminal API
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/trading-agent-ops/market-api
ExecStart=/opt/trading-agent-ops/market-api/.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
Restart=always
RestartSec=3
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

保存为：

```text
/etc/systemd/system/market-terminal-api.service
```

启动：

```bash
sudo systemctl daemon-reload
sudo systemctl enable market-terminal-api
sudo systemctl restart market-terminal-api
sudo systemctl status market-terminal-api
```

查看日志：

```bash
journalctl -u market-terminal-api -f
```

## 5. 前端部署

### 5.1 构建前端

```bash
cd market-terminal
npm ci
npm run build
```

构建产物：

```text
market-terminal/dist/
```

### 5.2 部署静态文件

将 `dist/` 同步到服务器目录：

```bash
sudo mkdir -p /opt/trading-agent-ops/market-terminal/dist
sudo rsync -a --delete market-terminal/dist/ /opt/trading-agent-ops/market-terminal/dist/
```

### 5.3 Nginx 配置

示例：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /opt/trading-agent-ops/market-terminal/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Connection "";

        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 3600s;
        add_header X-Accel-Buffering no;
    }

    location /health {
        proxy_pass http://127.0.0.1:8000/health;
        proxy_set_header Host $host;
    }
}
```

保存为：

```text
/etc/nginx/conf.d/market-terminal.conf
```

验证并重载：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

## 6. 一键部署脚本

仓库提供脚本：

```text
scripts/deploy-market-terminal.sh
```

该脚本适合在服务器上、从仓库根目录执行。

### 6.1 最小执行

```bash
sudo bash scripts/deploy-market-terminal.sh
```

默认行为：

- 安装前端依赖。
- 执行 `npm run build`。
- 同步前端 `dist/` 到 `/opt/trading-agent-ops/market-terminal/dist`。
- 同步后端代码到 `/opt/trading-agent-ops/market-api`。
- 创建后端 Python venv。
- 安装后端依赖。
- 如果不存在 `.env`，生成默认 `.env`。
- 生成 systemd 服务。
- 生成 Nginx 配置。
- 重启后端服务并 reload Nginx。

### 6.2 指定域名和行情源

```bash
sudo DOMAIN=your-domain.com \
  ADAPTER=eastmoney \
  TICK_INTERVAL=5.0 \
  bash scripts/deploy-market-terminal.sh
```

### 6.3 指定安装目录

```bash
sudo INSTALL_DIR=/srv/trading-agent-ops \
  DOMAIN=your-domain.com \
  bash scripts/deploy-market-terminal.sh
```

### 6.4 只部署应用，不改 Nginx

```bash
sudo SKIP_NGINX=1 bash scripts/deploy-market-terminal.sh
```

### 6.5 只部署文件，不改 systemd

```bash
sudo SKIP_SYSTEMD=1 bash scripts/deploy-market-terminal.sh
```

如果后端服务由其他进程管理，可以同时跳过健康检查：

```bash
sudo SKIP_SYSTEMD=1 \
  SKIP_HEALTHCHECK=1 \
  bash scripts/deploy-market-terminal.sh
```

部署完成后检查：

```bash
curl http://127.0.0.1:8000/health
```

检查 Nginx：

```bash
curl http://your-domain.com/health
```

检查 SSE：

```bash
curl -N http://your-domain.com/api/stream
```

打开页面：

```text
http://your-domain.com/
```

页面上应看到：

- 市场监控终端
- 行情监控
- 工具箱
- 今日清单
- 每日日记
- 实时行情或模拟数据

## 8. 常见问题

### 8.1 页面能打开，但没有行情

检查后端：

```bash
systemctl status market-terminal-api
journalctl -u market-terminal-api -n 100
curl http://127.0.0.1:8000/health
```

检查 Nginx 是否代理 `/api/`：

```bash
curl -N http://your-domain.com/api/stream
```

### 8.2 SSE 连接延迟或不刷新

确认 Nginx 配置包含：

```nginx
proxy_buffering off;
proxy_cache off;
proxy_read_timeout 3600s;
add_header X-Accel-Buffering no;
```

### 8.3 使用 eastmoney 没有数据

检查服务器是否能访问外部行情接口：

```bash
curl -I https://push2delay.eastmoney.com
curl -I https://query1.finance.yahoo.com
```

也可以临时改回模拟数据：

```env
ADAPTER=mock
TICK_INTERVAL=2.2
```

然后重启：

```bash
sudo systemctl restart market-terminal-api
```

### 8.4 清单和日记数据在哪里

当前前端构建化后的第一阶段仍使用浏览器 IndexedDB 保存清单和日记。

这意味着：

- 同一浏览器可保留数据。
- 换设备或换浏览器不可见。
- 清理浏览器数据可能丢失。

后端已有 `/api/checklist` 和 `/api/journal`，后续可以继续改造成服务端持久化。

## 9. HTTPS 建议

生产环境建议使用 HTTPS。可以使用 Certbot：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

签发后重新验证：

```bash
curl https://your-domain.com/health
```

## 10. 回滚

如果需要回滚：

1. 切回旧代码版本。
2. 重新执行部署脚本。
3. 或恢复 `/opt/trading-agent-ops/market-terminal/dist` 的上一版备份。
4. 重启后端：

```bash
sudo systemctl restart market-terminal-api
sudo systemctl reload nginx
```

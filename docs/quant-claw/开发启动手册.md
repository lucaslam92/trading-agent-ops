# Quant Claw 开发启动手册

## 1. 文档目的

本文档用于帮助开发者快速在本地启动 `quant-claw` 项目，并验证最小闭环是否可运行。

## 2. 环境要求

建议环境：

- Python `>= 3.11`
- Docker / Docker Compose
- 可选：Redis、Postgres 本地实例

## 3. 快速启动

在 `quant-claw/` 目录下执行：

```bash
cp .env.example .env
docker compose up -d redis postgres
python -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
python -m quant_claw.apps.run_demo
uvicorn quant_claw.api.app:app --reload
```

## 4. 环境变量

当前 `.env.example` 内容：

```env
APP_ENV=sim
REDIS_URL=redis://redis:6379/0
DATABASE_URL=postgresql://postgres:postgres@postgres:5432/quant_claw
LOG_LEVEL=INFO
```

说明：

- `APP_ENV`：运行环境，当前建议使用 `sim`
- `REDIS_URL`：Redis 连接地址
- `DATABASE_URL`：数据库连接地址
- `LOG_LEVEL`：日志级别

## 5. Docker Compose 服务

当前提供的基础服务包括：

### Redis

- 镜像：`redis:7-alpine`
- 端口：`6379`

### Postgres

- 镜像：`postgres:16-alpine`
- 数据库：`quant_claw`
- 端口：`5432`

### API

- 启动命令：`uvicorn quant_claw.api.app:app --host 0.0.0.0 --port 8000`
- 端口：`8000`

## 6. API 入口

当前 API 提供以下接口：

### `GET /health`

健康检查。

示例响应：

```json
{
  "status": "ok"
}
```

### `GET /events`

查询最近事件列表。

### `GET /positions`

查询当前持仓。

### `POST /simulate/funding`

触发一次模拟资金费率事件。

示例：

```bash
curl -X POST "http://127.0.0.1:8000/simulate/funding?symbol=BTCUSDT&annualized_rate=0.18"
```

## 7. 本地验证流程

建议按下面顺序验证：

1. 启动 Redis / Postgres
2. 安装项目依赖
3. 启动 API 服务
4. 调用 `/health` 确认服务正常
5. 调用 `/simulate/funding`
6. 再调用 `/events` 查看事件是否产生
7. 调用 `/positions` 查看持仓是否更新

## 8. 测试运行

当前仓库已包含 simulation 测试，可运行：

```bash
pytest
```

其中关键测试会验证：

- 模拟资金费率事件能否触发闭环
- 持仓是否成功生成
- 事件是否被落库

## 9. 常见问题

### 问题 1：接口起来了但没事件

排查方向：
- 是否触发了 `/simulate/funding`
- annualized_rate 是否高于策略阈值
- orchestrator 是否完成 setup

### 问题 2：没有持仓更新

排查方向：
- risk 是否通过
- trader 是否发出 `execution.order.requested`
- execution gateway 是否返回成交

### 问题 3：数据库没有记录

排查方向：
- Storage 是否初始化成功
- persistence service 是否正确挂接
- 数据库连接串是否有效

## 10. 推荐开发习惯

- 先在 simulation 路径做改动验证
- 每加一个新 topic 就补一个测试
- 先冻结 schema 再扩 Agent 逻辑
- 将 strategy / risk / execution 改动分层提交，避免耦合过深
